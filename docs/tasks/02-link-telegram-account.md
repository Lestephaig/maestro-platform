# Задача 2. Добавить привязку Telegram-аккаунта через сайт

## Зависимости

Сначала должна быть выполнена задача №1.

## Цель

Позволить авторизованному пользователю Maestro безопасно привязать свой Telegram через кнопку на сайте и одноразовую deep link-ссылку.

## Перед началом

Изучи текущую авторизацию, модель пользователя, настройки профиля, API, миграции и реализацию команды `/start`. Используй существующие UI-компоненты и соглашения проекта.

## Пользовательский сценарий

1. Пользователь нажимает «Привязать Telegram» в настройках аккаунта.
2. Backend создаёт одноразовый криптографически стойкий токен с ограниченным сроком действия.
3. Сайт открывает ссылку `https://t.me/<bot_name>?start=<token>`.
4. Пользователь запускает бота.
5. Бот проверяет токен и связывает `telegram_chat_id` с авторизованным аккаунтом Maestro.
6. Бот сообщает об успешной привязке, а сайт после обновления показывает статус «Telegram привязан».

## Требования

1. Добавь необходимые поля или отдельные таблицы для связи пользователя с Telegram и для одноразовых токенов.
2. Токен должен:
   - генерироваться безопасным генератором;
   - иметь TTL не более 15 минут;
   - использоваться только один раз;
   - храниться безопасно, предпочтительно в виде хеша;
   - быть связан с конкретным пользователем.
3. `telegram_chat_id` должен быть уникальным: один Telegram-аккаунт нельзя незаметно привязать к нескольким пользователям.
4. Не использовать Telegram username как идентификатор привязки.
5. Обработай просроченный, повторно использованный и неизвестный токен понятным сообщением.
6. Добавь возможность отвязать Telegram с подтверждением. После отвязки отправка уведомлений должна прекращаться.
7. При повторной привязке не создавать дублирующие связи.
8. Добавь API получения статуса привязки, создания ссылки и отвязки аккаунта.
9. Добавь защиту API авторизацией, проверками прав и разумным rate limit для создания токенов.
10. Добавь миграции и тесты успешного сценария, истечения токена, повторного использования и конфликта `chat_id`.

## Не входит в задачу

- Отправка уведомлений о новых сообщениях.
- Общие переключатели каналов уведомлений.
- Подписки на объявления и музыкантов.

## Критерии приёмки

- Привязка выполняется только через действующий одноразовый токен.
- Telegram-аккаунт корректно отображается в настройках Maestro.
- Токен нельзя использовать повторно или для другого пользователя.
- Пользователь может отвязать и затем снова привязать Telegram.
- Миграции применяются и откатываются штатным способом, тесты проходят.

## Отчёт по завершении

Опиши изменённые модели и endpoints, TTL токена, обработанные конфликтные сценарии и результаты тестов.
