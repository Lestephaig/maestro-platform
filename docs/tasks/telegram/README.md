# Интеграция Maestro с Telegram: набор задач

Файлы в этой папке — самостоятельные задания для Cursor или Codex. Каждое задание следует выполнять отдельным этапом после проверки предыдущего.

## Рекомендуемый порядок

1. `01-create-telegram-bot.md`
2. `02-link-telegram-account.md`
3. `04-notification-channel-settings.md`
4. `03-new-message-notifications.md`
5. `05-telegram-link-banner.md`
6. `06-route-notifications-through-bot-server.md`
7. `07-ad-subscription-settings.md`
8. `08-ad-creation-notifications.md`
9. `09-musician-subscription-settings.md`
10. `10-new-musician-notifications.md`

Задача №4 выполняется перед №3, потому что отправка уведомлений должна сразу учитывать общие настройки каналов пользователя.
Задача №6 выполняется сразу после №5, чтобы все последующие Telegram-уведомления
сразу использовали зарубежный шлюз и не обращались к Telegram API с сервера платформы.

## Общие правила для всех этапов

- Перед изменениями изучить `AGENTS.md`, `README`, архитектуру проекта, модели данных, существующие сервисы email-уведомлений, фоновые задачи и правила оформления интерфейса.
- Использовать текущий стек и существующие абстракции проекта. Не добавлять новый фреймворк или инфраструктурный компонент без необходимости.
- Не дублировать бизнес-логику и справочники типов исполнителей, голосов, инструментов, объявлений, стран и городов.
- Сохранять обратную совместимость. Не ломать существующие email-уведомления и пользовательские сценарии.
- Все внешние вызовы выполнять вне основной транзакции и не допускать, чтобы недоступность Telegram или почтового сервиса блокировала действия пользователя.
- Секреты хранить только в переменных окружения. Не выводить токены и персональные данные в логи.
- Добавлять миграции, тесты и документацию для каждого нового поведения.
- Не изменять несвязанные части проекта. Не выполнять крупный рефакторинг без прямой необходимости.
- После каждого этапа запустить релевантные тесты и линтеры, затем кратко перечислить изменённые файлы, принятые решения, результаты проверок и оставшиеся ограничения.

## Общий результат

Пользователь Maestro может безопасно привязать Telegram, независимо включать email- и Telegram-уведомления, получать уведомления о личных сообщениях, а также подписываться на новые объявления и появление подходящих музыкантов.
